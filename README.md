# Crate

A free, local-only tool for organizing a Rekordbox library and building new crates from it.

**Live site:** _add your GitHub Pages URL here once it's deployed_

## What it does

- Reads a Rekordbox XML export (`File → Export Collection in xml format`) — nothing uploads anywhere, everything runs in the browser
- Organizes your library: sortable/searchable table, your own notes and tags, health checks (missing genre/key/BPM, duplicates, orphaned tracks), and genre cleanup suggestions
- Builds new crates: filter by BPM, harmonic key (Camelot), genre or genre groups, order by BPM, key, a smart harmonic mix, or a target energy shape
- Groups several crates into a **Gig** with ordered blocks, runtime totals, and a printable set sheet
- Exports as `.m3u8`, a merged Rekordbox XML, CSV, or an experimental Traktor NML

## Files

- `index.html` — landing page
- `app.html` — the tool itself
- `manual.html` — the guide/reference manual

## Running locally

No build step. Clone the repo and open `index.html` in a browser, or serve the folder with anything static (`python3 -m http.server`, etc).

## Deploying

This repo is set up to be served directly by GitHub Pages from the `main` branch — see the guide the author used at [claude.ai](https://claude.ai) or just enable Pages in the repo settings and point it at `main` / root.

## Status

Actively used and maintained by one person. Traktor export is explicitly experimental — see the guide before relying on it.
